🇬🇧 English
🎯 Description
Weather Match Adventure is a simple matching game designed for kindergarten children (ages 5–6).
Children match weather types with the correct item or action.
The game runs completely offline as a single HTML file.

🌤️ Matching Pairs
This version includes:
    • ☀️ Sunny → 🕶️ Sunglasses
    • 🌧️ Rain → ☂️ Umbrella
    • ❄️ Snow → 🧤 Gloves
    • 💨 Wind → 🪁 Kite
    • ⚡ Thunder → 🏠 Stay inside
    • ☁️ Cloudy → 🧺 Picnic basket
Teachers can enable/disable pairs from the settings panel.

⭐ Positive Feedback
Children receive encouraging messages:
    • “Excellent!”
    • “Perfect!”

👶 Features for Children
    • Character selection (emoji avatars)
    • Player name input
    • 3 progressive levels (2 → 4 → 6 matches)
    • Visual feedback and animations
    • Sounds generated with Web Audio API
    • Optional read-aloud mode (SpeechSynthesis API)

👩‍🏫 Teacher Features
Settings panel (⚙️):
    • Language switch: Romanian / English
    • Game mode:
        ◦ Tap-to-match
        ◦ Drag-and-drop
    • Select active pairs
    • Automatic browser saving (localStorage)
